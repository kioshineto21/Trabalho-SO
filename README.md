## Estrutura

```
site/
├── index.html        Página principal (todas as seções)
├── prompts.html      Página com os prompts usados na IA
├── style.css         Estilos (dark mode, glass, animações)
├── script.js         Simulador, comparador, quiz, radar, terminal
├── assets/           Recursos extras (vazia — usar se precisar)
└── images/           Imagens (vazia — usar se precisar)
```

## Como rodar localmente

Basta abrir `index.html` no navegador. Tudo é HTML/CSS/JS puro, sem build.

## Como publicar no Netlify

1. Acesse https://app.netlify.com/
2. Arraste a pasta `site/` inteira para a área "Drag and drop your site folder here"
3. Pronto — Netlify gera uma URL automaticamente.

Também funciona em GitHub Pages e Vercel sem qualquer ajuste.
